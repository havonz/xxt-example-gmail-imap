# utils.video_to_album

Purpose: Import video to album

## Signature
```lua
utils.video_to_album(video_file_name)
```

## Example
```lua
utils.video_to_album("/var/mobile/1.mp4")
```

## Parameters
- video_file_name
    string, video file name. Supported formats are `mp4`, `m4v`, and `mov`.

## Notes
Saves `mp4`, `m4v`, and `mov` videos to the album.
