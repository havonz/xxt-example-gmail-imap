# Dialog:set_title

Purpose: Configure a dialog title.

## Signature
```lua
dialog_object = dialog_object:set_title(title_text)
```

## Example
```lua
dialog():set_title('Title'):show()
```

## Parameters
- title_text
    string, the dialog title.

## Returns
- dialog_object
    Dialog, returns the dialog itself.

## Notes
Configures the dialog title.
