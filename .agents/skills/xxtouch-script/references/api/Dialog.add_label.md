# Dialog:add_label

Purpose: Add a text label to a dialog.

## Signature
```lua
dialog_object = dialog_object:add_label(label_content)
```

## Example
```lua
dialog():add_label('Text Label'):show()
```

## Parameters
- label_content
    string, the text displayed by the label.

## Returns
- dialog_object
    Dialog, returns the dialog itself.

## Notes
Adds a text label to the dialog.
